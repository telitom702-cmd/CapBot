# AI Caption Bot

Telegram AI Caption Generator/Editor.

## Features

- /start
- /help
- /settings
- AI caption generation/editing
- বাংলা
- English
- हिन्दी
- 한국어
- Modular plugins
- Detailed logging
- Render/Docker ready

## Environment Variables

```text
SESSION=
API_ID=
API_HASH=
BOT_TOKEN=
AI_API_KEY=
AI_MODEL=gpt-4o-mini
```

## Run

```bash
pip install -r requirements.txt
python bot.py
```

## Logs

Logs are printed to the terminal and saved to:

```text
bot.log
```

Errors include filename and line number.
